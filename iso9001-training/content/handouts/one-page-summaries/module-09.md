# Module 9 Summary: Improvement and Corrective Action

*This material is an original training aid. It is not a substitute for the standard. Obtain ISO 9001 from ISO or a national standards body.*

**{{COMPANY}} one-page summary. Applies to: all roles (required).**

## Key points

- A **correction** fixes the nonconforming output. A **corrective action** removes the cause so that it does not recur.
- When a nonconformity occurs: react, find the cause, check whether similar problems exist, act, and review effectiveness.
- Root cause is a process or system condition. Ask why the system allowed the error.
- Root-cause methods: 5 Whys, cause-and-effect (fishbone) diagram, Pareto analysis.
- {{COMPANY}} continually improves using data, audits, and management review.

## Do

- Offer a cause, not only a description, when you report a problem.
- Check later that an action worked, and record the result.
- Share improvement ideas.

## Do not

- Stop at "operator error".
- Use retraining as the only action.
- Close an action without checking its effectiveness.
