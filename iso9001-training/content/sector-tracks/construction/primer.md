## 1. The sector at a glance

Construction and engineering work is delivered as projects. The work item is a work package or deliverable, such as a slab pour or a window installation. Quality depends on current drawings at the work front, inspection and test plans with hold points, evaluated subcontractors, traceable materials and pours, verified test equipment, and controlled changes from the client and the design team.

**Process map (Meridian Build).** Tender and requirements review → Design and planning → Site execution → Inspection and testing → Handover review → Close-out and warranty. The work item is the **work package**. The constraint stage, where work most often queues, is site execution.

| Stage | Typical inputs | Typical outputs | Typical owner |
|---|---|---|---|
| 1. Tender and requirements review | Tender documents, client requirements, contract terms | Reviewed requirements and accepted contract | Bid manager |
| 2. Design and planning | Requirements, design standards, surveys | Drawings, inspection and test plans, programme | Design manager and planner |
| 3. Site execution | Drawings, materials, subcontractors, method statements | Built work packages | Site manager and foremen |
| 4. Inspection and testing | Inspection and test plans, test equipment, hold points | Inspection records and test results | Site engineer and inspectors |
| 5. Handover review | Completed works, records, snag lists | Handover file and client sign-off | Project manager |
| 6. Close-out and warranty | Defect reports, warranty terms | Corrected defects and lessons learned | Aftercare lead |

The inspection and test plan (ITP) lists each check, who does it, and which checks are hold points that must be released before work continues.

Each likely cause is a system condition, not a person. When a cause names a person ("careless", "forgot"), ask what in the system allowed the event and what would prevent it for anyone in that role.

| No. | Nonconformity | Clause | Likely root cause (system condition) | Preventive control |
|---|---|---|---|---|

| 2 | Work covered before a hold point is released | 8.6 | Hold points can be marked by anyone | Only the named authority signs |
| 3 | Subcontractor starts without evaluation | 8.4 | Approval list not checked at site induction | Induction checks approval |

## 5. Sector specifics

### Customer property

Client property includes client drawings and models, client-supplied materials and fittings, site access granted by the client, and existing structures. Protect it, record its condition, and report damage.

### External providers

Subcontractors, material suppliers, testing laboratories, and plant hire. Evaluate subcontractors before they start, issue them current drawings, and review their material changes.

### Measuring and monitoring resources

Survey instruments, concrete and soil test equipment, cube presses, and pressure and torque gauges. Verify them at set intervals and consider test conditions such as curing.

### Work environment

Weather, access, lighting, and noise affect work. Site safety is managed separately and is outside this program.

## 6. Sector vocabulary

| Term | Meaning in this primer |
|---|---|
| Work package | A defined part of the project; the work item |
| Deliverable | An output handed to the client |
| ITP | Inspection and test plan |
| Hold point | A point where work stops until a named person releases it |
| Witness point | A point where a party may attend an inspection |
| Pour | A placement of concrete |
| Pour record | The record of a pour, trucks, and elements |
| Cube test | A strength test on concrete samples |
| Curing | Keeping concrete or samples under set conditions |
| Delivery ticket | The record of a concrete truck load |
| Element | A part of the structure, such as a column |
| Setting out | Marking positions on site from drawings |
| Drawing register | The list of current drawings and revisions |
| Shop drawing | A drawing prepared by a fabricator |
| Method statement | A document describing how work will be done |
| Snag list | A list of minor defects to fix before handover |
| Handover | Transfer of completed work to the client |
| Aftercare | Support after handover, including defects |
| Substitution | Use of a product other than the one specified |
| Programme | The project schedule |
| Client engineer | The client's representative who inspects |
| Interface | Where the work of two disciplines meets |
