# Sector Drills: IT and Software Services

*This material is an original training aid. It is not a substitute for the standard. Obtain ISO 9001 from ISO or a national standards body.*

These drills extend the it and software services sector quiz with Translate items and a scenario sort. They are untimed. In the Sector Casebook (Drills), each answer shows feedback at once and missed items return until they are secure; the pass mark for the track is 80 percent on the first try. Option order is shuffled on screen. Clause tags use 2015 numbering and are unverified. **[VERIFY]** Role tags: F frontline, T technical, S supervisor.

## Part 1: Multiple-choice items

**IT-D01.** A release is deployed with recorded test failures and no risk acceptance. Which requirement is most affected?

- A) Organizational context
- B) Quality policy
- C) Release of products and services
- D) Infrastructure

**Answer: C.** Release follows verification or authorized acceptance. *(Cl. 8.6; T, S)*

**IT-D02.** A story has no acceptance criteria. What is the issue?

- A) The requirement cannot be verified
- B) Nothing; developers will decide
- C) It is a security issue
- D) It must be deleted

**Answer: A.** Requirements need enough detail to design and test against. *(Cl. 8.2.2; T)*

**IT-D03.** The test database is two versions behind production and nobody has compared them. Which requirement applies?

- A) Customer communication
- B) Policy
- C) Management review
- D) Suitability of monitoring and measuring resources

**Answer: D.** Tests verify only if the environment represents production. *(Cl. 7.1.5; T)*

**IT-D04.** An urgent fix is deployed without a ticket. What is the correct view?

- A) Urgent fixes are exempt
- B) Urgent changes still need a record and approval, through a shortened route if defined
- C) Only a verbal note is needed
- D) Record it at year end

**Answer: B.** Changes are controlled, including urgent ones. *(Cl. 8.5.6; T, S)*

**IT-D05.** A support analyst exports customer records to a laptop to investigate. What is required?

- A) Nothing if the analyst is careful
- B) Authorization and protection of customer data as customer property
- C) Deleting the data later
- D) Telling a colleague

**Answer: B.** Customer data is customer property. *(Cl. 8.5.3; F, T)*

**IT-D06.** A peer review was approved by the author's second account. What is the problem?

- A) The review was too fast
- B) Two accounts are always forbidden
- C) Nothing
- D) The review is not independent

**Answer: D.** Effective review is independent of the author. *(Cl. 8.5.1; T)*

**IT-D07.** Export tests run only after merge. What does this risk?

- A) Regressions reach the release before they are detected
- B) Faster builds only
- C) Nothing
- D) Security breaches

**Answer: A.** Checks at the right stage stop nonconforming output moving on. *(Cl. 8.5.1; T)*

**IT-D08.** A problem record says "developer oversight; be careful". What is missing?

- A) A longer description
- B) The developer's name
- C) A system cause, an action that removes it, and an effectiveness check
- D) Nothing

**Answer: C.** Corrective action addresses causes, not people. *(Cl. 10.2; T, S)*

**IT-D09.** Who should accept a release with known high-severity defects?

- A) The developer who wrote the change
- B) Anyone on the team
- C) The defined authority, recorded, and the customer where the contract requires
- D) Nobody ever

**Answer: C.** Authority for risk acceptance is defined. *(Cl. 8.6, 5.3; S)*

**IT-D10.** The release note is informal in tone. Is this a nonconformity?

- A) Not by itself, unless a requirement sets the wording
- B) Yes, always
- C) Yes, a major one
- D) Only on Fridays

**Answer: A.** Tone is a style matter unless required. *(Cl. 7.5.2; F)*

**IT-D11.** A library upgrade from 3.2 to 4.0 was merged without reading its change notes. What is the best response?

- A) Ban all libraries
- B) Ignore it
- C) Rewrite the library
- D) Review major updates of external components for their effect

**Answer: D.** External components are evaluated, especially for major changes. *(Cl. 8.4; T)*

**IT-D12.** Nobody owns the export test suite and its failures are not assigned. Which clause is most affected?

- A) Calibration
- B) Roles, responsibilities, and authorities
- C) Customer property
- D) Design inputs

**Answer: B.** Responsibilities for quality activities must be assigned. *(Cl. 5.3; S)*

**IT-D13.** A customer contract requires five days' notice of calculation changes. A hotfix is planned in two days. What is needed?

- A) Nothing; it is a hotfix
- B) Written customer agreement to the shorter notice
- C) A discount
- D) Deploy at night

**Answer: B.** Customer requirements on change notice must be met. *(Cl. 8.2.3; S)*

**IT-D14.** Tickets older than target are reported weekly but nobody reviews the report. What is this?

- A) A major nonconformity in all cases
- B) A security issue
- C) Not relevant
- D) An opportunity to improve analysis and use of data

**Answer: D.** Data should be analyzed and used. *(Cl. 9.1.3; S)*

**IT-D15.** Only one engineer knows how the formatter works. Which requirement is at risk?

- A) Organizational knowledge
- B) Customer satisfaction
- C) Policy
- D) Infrastructure

**Answer: A.** Knowledge needed to operate must be maintained. *(Cl. 7.1.6; S)*

**IT-D16.** A deployment log shows two different builds under one release name. What breaks?

- A) Competence
- B) Leadership
- C) Identification and traceability of the release
- D) Context

**Answer: C.** The organization must know exactly what is deployed where. *(Cl. 8.5.2; T)*

**IT-D17.** A manager calls test sign-off "a formality". Which clause is most relevant?

- A) Calibration
- B) Purchasing
- C) Leadership and commitment
- D) Context

**Answer: C.** Leaders support the quality system, including release controls. *(Cl. 5.1.1; S)*

**IT-D18.** Customer tickets about the same symptom were closed as "user error". What should happen?

- A) Link and review them as possible evidence of a nonconforming output
- B) Nothing
- C) Delete them
- D) Reply with a template

**Answer: A.** Feedback is evaluated; similar reports may show a defect. *(Cl. 9.1.2, 8.7; F, T)*

## Part 2: Translate items

A Translate item asks you to restate a general requirement in the language of this sector, or to restate a sector example as the underlying requirement.

**IT-T01.** Which example restates "measuring resources must be suitable and verified"?

- A) The team has a stand-up
- B) The backlog is ordered
- C) Code is formatted
- D) The test environment is compared with production and the result recorded

**Answer: D.** In software, the test environment is a measuring resource. *(Cl. 7.1.5; T)*

**IT-T02.** "Release 12.6 went live with two failing time-zone tests accepted by the author." Which general requirement does this restate?

- A) Competence must be recorded
- B) Release requires completed verification or authorized approval
- C) Objectives must be measurable
- D) Scope must be documented

**Answer: B.** Author acceptance is not authorized approval. *(Cl. 8.6; S)*

**IT-T03.** Which example restates "customer property is identified, protected, and safeguarded"?

- A) The office is tidy
- B) Customer records are accessed only through an authorized route and never copied to personal devices
- C) Release notes are written
- D) Tickets are numbered

**Answer: B.** Customer data is customer property. *(Cl. 8.5.3; F)*

**IT-T04.** "CHG-881 was edited after approval to add a second fix." Which general requirement does this restate?

- A) Context is reviewed
- B) Policy is communicated
- C) Audits are planned
- D) Changes are reviewed and approved as they will be implemented

**Answer: D.** The approved change must match what is released. *(Cl. 8.5.6; T)*

**IT-T05.** Which example restates "documented information at the point of use is the current version"?

- A) The repository links to the current controlled coding standard
- B) The team uses chat
- C) The wiki has a logo
- D) Builds are fast

**Answer: A.** Point of use in software is the tool or repository. *(Cl. 7.5.3; F)*

**IT-T06.** "Requirement TZ-4 lists six time zones; tests cover two." Which general requirement does this restate?

- A) Customer feedback must be monitored
- B) Resources must be provided
- C) Design verification must cover the stated requirements
- D) Risks must be addressed

**Answer: C.** Verification covers stated requirements. *(Cl. 8.3; T)*
